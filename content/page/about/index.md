## 🛠️ 本站技术栈

### 核心框架

- **[Hugo](https://gohugo.io/)** - 高性能静态网站生成器
- **[Stack Theme](https://github.com/CaiJimmy/hugo-theme-stack)** - 现代化 Hugo 主题

### 部署架构

```
用户访问
    ↓
Cloudflare CDN (全球加速 + DDoS 防护)
    ↓
Nginx (Web 服务器 + 反向代理)
    ↓
Docker 容器 (Hugo 静态文件)
```

### 基础设施

- **Web 服务器**：Nginx
- **容器化**：Docker + Docker Compose
- **CDN**：Cloudflare
- **CI/CD**：GitHub Actions
- **SSL**：Cloudflare SSL/TLS

### 集成服务

- **评论系统**：[Giscus](https://giscus.app/) (基于 GitHub Discussions)
- **访问统计**：Google Analytics
- **搜索功能**：内置 Fuse.js 全文搜索
